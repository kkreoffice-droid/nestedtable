# Privacy Policy for NestedTable Manager

**Effective Date:** November 17, 2026

NestedTable Manager ("the Add-on") is a Google Sheets Editor Add-on designed to help users view and manage parent-child relational data across spreadsheet tabs.

## 1. Information We Access
To function properly inside Google Sheets, the Add-on requests authorization for the following Google API scopes:
- **`https://www.googleapis.com/auth/spreadsheets`**: Used strictly to read sheet headers, fetch parent and child rows, and write cell edits or row updates directly back to your active Google Spreadsheet.
- **`https://www.googleapis.com/auth/script.container.ui`**: Used strictly to display the NestedTable Manager dialog and sidebar user interface inside Google Sheets.

## 2. How We Use and Store Your Data
- **Local Processing Only:** All spreadsheet data accessed by NestedTable Manager is processed strictly within your active Google Workspace session.
- **No External Servers:** We do **not** transmit, store, copy, or log your spreadsheet data, personal information, or Google account details on any external servers or third-party databases.
- **No Data Sharing:** We do not sell, rent, trade, or share user data with any third parties.

## 3. Google API Services User Data Policy
NestedTable Manager's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.
