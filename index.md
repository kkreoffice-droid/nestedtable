# NestedTable Manager for Google Sheets

**NestedTable Manager** is a Google Sheets Editor Add-on that lets you view, edit, and synchronize parent-child relational tables inside a split-grid dialog interface.

## Key Features
- **Split-Grid Interface:** View parent records on top and filtered child records below.
- **Direct Sheet Sync:** All edits, row additions, and deletions sync immediately with your Google Sheets tabs.
- **Custom Views:** Configure multiple parent-child relationships using a simple `Settings` sheet.
- **Keyboard Shortcuts & Undo/Redo:** Built-in `Ctrl+D` / `Ctrl+R` fill shortcuts and session undo/redo history.

## How to Use
1. Open any Google Sheet and go to **Extensions** → **NestedTable** → **Initialize Settings**.
2. Configure your Parent Sheet, Child Sheet, and matching ID columns in the `Settings` tab.
3. Go to **Extensions** → **NestedTable** → **Open Manager** to launch the interface.
